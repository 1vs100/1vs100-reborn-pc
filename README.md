# 1 vs 100 PC

- Play the Xbox 360 game show 1 vs 100 on Windows, Linux or macOS.
- Play online on the community server, together with Xbox players.
- Use your own Avatar and gamertag.
- Bring your own game files. This project ships no game content.

- Website: [1vs100.fans](https://1vs100.fans)
- Help and chat: [Discord](https://discord.gg/tV3ajhwFTf)

## Play

1. Download the file for your computer from the [latest release](https://github.com/1vs100/1vs100-reborn-pc/releases/latest).
2. Install or extract it, then open the launcher.
3. Add your game files, pick a gamertag and an Avatar, and press **Launch**.

The [PC setup guide](https://docs.1vs100.fans/pc/) walks you through each step with screenshots, and covers controls and common problems.

The game is still early. Expect bugs, and please report them on [Discord](https://discord.gg/tV3ajhwFTf).

## Privacy

The game never contacts Xbox LIVE or other Microsoft services. It talks only to the game server set in the launcher. Your profile, Avatar and stats stay on your computer.

## Development

The PC version is the Xbox 360 game rebuilt with the [ReXGlue](https://github.com/rexglue/rexglue-sdk) static recompiler. Building it, running it by hand, all settings and the code layout are in [DEVELOPMENT.md](DEVELOPMENT.md).
